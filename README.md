# Journey Forensics

AI-powered customer journey investigation and analytics platform.

## Purpose

Journey Forensics analyzes customer and business data to identify
where customers experience problems, investigate potential causes,
and communicate evidence-backed business insights.

## Initial Domain

Travel / Hospitality

## Core Technologies

- Python
- SQL
- PostgreSQL
- Pandas
- NumPy
- FastAPI
- Next.js
- React
- Power BI
- DAX
- LLM / AI APIs
